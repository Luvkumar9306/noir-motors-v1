# NOIR MOTORS — Luxury Automotive Showcase (noir-motors-v1)

> A high-end luxury automotive digital experience featuring a cinematic 3D Ferrari 458 showcase, curated vehicle gallery, dynamic lighting, and concierge booking.

---

## ?? Key Features

* **3D Hero Showcase:** Real-time 3D Ferrari 458 Italia with cinematic scroll-driven camera rotation and metallic reflection rendering (Three.js r128 + DRACO compression).
* **Curated Fleet Gallery:** Detailed showcase for Ferrari SF90 Stradale, Porsche 911, Rolls-Royce Cullinan, Range Rover, and AMG GT.
* **Concierge Booking:** Integrated reservation and private viewing scheduling interface.
* **Apple-Inspired Dark Aesthetic:** Deep black (#000000), frosted acrylic panels, and refined typography.

---

## ?? Running Locally

Open index.html directly in your browser or run a lightweight local static server:

``bash
python -m http.server 8080
``
Then visit http://localhost:8080.
